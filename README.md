# 이재민 | 게임기획 포트폴리오

전투 규칙, 밸런스, UI와 콘텐츠를 기획하고 프로토타입과 플레이 결과로 확인한 작업을 모았습니다. 프로젝트별로 본인, 팀, AI의 역할을 구분합니다.

**[포트폴리오 보기](https://gd-jm.github.io/game-portfolio-netmarble-neo/)**

## 저장소 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 포트폴리오 첫 화면 |
| `p/` | 프로젝트별 소개 |
| `assets/` | 소개에 쓰는 이미지, 영상 등 |
| `docs/` | 공개용 기획 자료, 회고와 발췌 자료 |
| `자료실_전체판.html` | 작업 자료 모음 |

별도 빌드 과정이 없는 정적 웹사이트입니다. 로컬에서는 `index.html`을 브라우저로 열 수 있으며, 외부 링크와 온라인 영상에는 인터넷 연결이 필요합니다.

## 수정과 공개 기준

[기여 및 브랜치 규칙](CONTRIBUTING.md)을 따릅니다. 프로젝트 소개는 실제 담당 범위와 근거를 유지하고, 완료한 일과 남은 검수를 구분합니다. 팀 자료와 외부 에셋은 공개 권한을 확인한 범위에서 사용합니다.

사이트와 자료의 공개가 원본 게임 전체의 공개나 자유로운 재사용 허용을 뜻하지는 않습니다. 각 프로젝트와 외부 자료의 권리, 이용 조건을 따릅니다.
