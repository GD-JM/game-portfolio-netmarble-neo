# BLINDSPOT

누군가에게 사각을 맡겨야 안전하게 정보를 모을 수 있지만, 새로 얻은 정보가 협력 관계를 바꾸는 **8인 꼬리잡기 생존 게임**입니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 구분 | 개인 게임 프로젝트 |
| 환경 | Unity 6, Windows |
| 핵심 기획 | 제한된 시야, 정보 수집, 협력과 배신의 판단 |
| 구현 구성 | 사람 1명과 봇 7명의 싱글플레이, 직접 LAN 접속 |

## 설계에서 다룬 문제

- **협력할 이유:** 조사 중의 사각을 다른 사람이 지키고, 조사한 사람과 경계한 사람이 각각 보상을 받도록 설계했습니다.
- **신뢰할 근거:** 정보를 자동으로 모두 공유하지 않고, 어떤 카드를 상대에게 보여줄지 선택하게 했습니다.
- **관계가 바뀌는 판단:** 정보를 얻을수록 함께 살아남을 이유와 배신할 이유를 다시 판단하게 했습니다.

## 작업과 공개 범위

개인 포트폴리오 프로젝트로 기획하고 AI와 구현을 진행했습니다. 개발 원본에는 설계, 코드, 검증 기록과 내부 작업 자료가 함께 있어 비공개로 관리합니다.

이 문서는 프로젝트 소개입니다. 자동 검사나 봇 경기 결과를 사람 사이의 재미 또는 밸런스가 검증되었다는 근거로 제시하지 않습니다. 공개 실행 파일은 이 문서에서 제공하지 않습니다.
