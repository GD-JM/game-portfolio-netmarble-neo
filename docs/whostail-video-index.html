건물 옥상 활공, 전화부스 타깃 조회, 로비 진입, 튜토리얼, QTE 세 가지는 이미 확보했습니다. 아래는 현재 원본으로 대체하기 어려운 부분입니다.

  1. 우선 1 · 30–60초

    친구와 메시지·통화·추격

    친구가 들어온 대기실에서 시작. 메시지 수신 배너를 클릭해 답장한 뒤 통화하고, 서로 추격하는 장면까지.

    현재 영상에서 가장 부족한 실제 멀티플레이 관계 행동을 보완.
  2. 우선 1 · 30–45초

    탈락 → 관전 → 중개자

    내가 잡히기 5초 전부터 녹화. 관전 진입과 대상 변경, 가능하면 중개자 참여·종료까지.

    관전자 UI 작업을 실제 입력과 결과로 보여주기.
  3. 우선 1 · 30–45초

    꼬리셔플 전후

    셔플 발생 직전부터 연출 전체와 새 타깃·꼬리색, 휴대폰 추리 변화까지 연속으로.

    관계가 뒤집히는 이벤트의 차별성을 보여주기. 꼬리 길이 이벤트로 대체하지 않음.
  4. 우선 1 · 25–40초

    승리 결과 → 한 판 더

    마지막 QTE 직전부터 결과·순위 화면을 3초 이상 유지하고 다음 판으로 이동.

    게임 전체 흐름의 끝과 반복 플레이를 완성.
  5. 우선 2 · 15–25초

    우산으로 실제 추격을 끊는 결과

    친구가 바로 뒤에서 따라오는 상태로 옥상 출발. 우산으로 다른 경로 착지 후, 친구가 놓치는 모습까지. 가능하면 친구 시점도 함께.

    옥상 활공과 계단 이탈 영상은 확보. 완전히 따돌렸다는 결과만 추가하면 됨.
  6. 우선 2 · 항목당 15–30초
